# Фотографии

Использование снимков из прежнего сайта подтверждено пользователем. Сохранены реальные снимки реки, коттеджа, бани, территории и вечернего вида. Оригинальные кадры в галерее оптимизированы в WebP, без добавления деталей. По просьбе пользователя фото реки для главного экрана отдельно обработано с помощью генеративного восстановления: увеличено до 1672 × 940 px, исправлены артефакты и цвет. Это художественно восстановленная версия исходного снимка; мелкие детали не следует считать документально точными. Файл `river-premium.webp` предназначен для первого экрана; оригинальный `river.webp` сохранён. Фото `photo1.jpg` в прежнем проекте не распознаётся и не используется. Изображения с названием `banya2.jpg` показывают постройку среди деревьев; на новом сайте снимок подписан только «Территория», без идентификации объекта.

Нужны дополнительные реальные фото:

- Барнхаус № 1: фасад, общий вид внутри, спальные места и подтверждённое оснащение.
- Барнхаус № 2: отдельный набор фото, чтобы не перепутать два домика.
- Коттедж: интерьер и зоны размещения.
- Баня: интерьер и подтверждённое оснащение.
- Чан: общий вид, расположение, детали.
- Гриль-домик: фасад, интерьер, подтверждённое оснащение.
- Территория: общий план и детали; широкоформатный вид реки для первого экрана.

Просим владельца подтвердить идентификацию коттеджа и бани из прежнего архива, актуальность каждого снимка и право на публикацию. Не публикуйте узнаваемые изображения гостей без их разрешения.

## Как добавить

1. Подготовьте WebP или JPEG. Рекомендуемая ширина: первый экран 1920–2400 px, карточки 1000–1400 px, галерея до 1600–2000 px. Стремитесь к 150–350 КБ на файл; проверьте резкость. Названия латиницей: `barn-1.webp`, `tub.webp`.
2. Положите файлы в `public/images/`.
3. В `src/data/site.ts` замените `image: null` соответствующего объекта на `image: '/images/barn-1.webp'`. Так же заполните запись в `gallery`. Для первого экрана используйте `heroImage`.
4. В `gallery` для каждого снимка задайте точные `title` и `subtitle`. Дополнительные кадры можно добавлять отдельными записями массива.
5. Соберите `npm run build` и проверьте `npm start`. После push GitHub Actions обновит публикацию.

Не добавляйте `public` в URL, не вписывайте имя репозитория в поле `image`: префикс пути добавляется автоматически. Для загрузки ошибок предусмотрена подписанная заглушка. После замены всех эскизов измените примечание под галереей в `page.tsx`.

Локальные шрифты поставляются пакетами Fontsource. Их лицензии SIL Open Font License сохранены в пакетах; файлы лицензий включены также в `docs/licenses/`.
