# Подключение реальной отправки

GitHub Pages размещает статические файлы. Для отправки нужен внешний HTTPS-endpoint: ваш сервер, serverless-функция или адаптер к сервису форм. Endpoint из `NEXT_PUBLIC_BOOKING_ENDPOINT` публичен. Токены почтового сервиса, Telegram-бота и прочие секреты храните только на сервере.

## Контракт

Форма делает `POST` с `Content-Type: application/json`:

```json
{
  "object": "cottage",
  "objectName": "Коттедж",
  "date": "2026-12-20",
  "departure": "2026-12-22",
  "guests": 4,
  "name": "Имя гостя",
  "phone": "+7 ...",
  "comment": "Комментарий",
  "timeZone": "Asia/Irkutsk"
}
```

- Проживание: `date`, `departure`, без `time` и `durationHours`.
- Баня и гриль-домик: `date`, `time`, `durationHours`, без `departure`.
- Чан: `date`, `time`, `comment`, без `departure` и `durationHours`. Почасовой расчёт отсутствует.
- Гости, имя, телефон, комментарий и часовой пояс передаются для всех объектов. Время относится к Тулуну (UTC+8).

Сервер возвращает HTTP 2xx и `{"accepted":true}` **только после реального принятия запроса в надёжную очередь или канал доставки**. Любой другой статус или тело показывают ошибку, а не успешную отправку. Таймаут клиента — 20 секунд. При таймауте доставка не подтверждена: на сервере предусмотрите защиту от дубликатов при повторе. При успешном принятии форма сообщает о приёме сервисом, сохраняя необходимость подтверждения владельцем.

## Обязательная серверная часть

1. Повторно валидировать все поля, допустимые ID объектов и формат дат. Клиентская проверка не защищает endpoint.
2. Ограничить длину имени и комментария, размер запроса, частоту запросов; предусмотреть антиспам и дедупликацию.
3. Разрешить CORS только с вашего реального origin; обработать preflight OPTIONS. Origin для GitHub Pages — `https://USERNAME.github.io`, без подпапки.
4. Не доверять переданной цене: форма не отправляет цену, тарифы проверяются владельцем.
5. Реализовать хранение/доставку, мониторинг и правила обработки данных. Не логировать телефоны в общедоступные журналы.
6. До подключения опубликовать реальные документы о персональных данных и добавить требуемое согласие.

## Включение

Локально скопируйте `.env.example` в `.env.local`, задайте `NEXT_PUBLIC_BOOKING_ENDPOINT=https://...` и пересоберите. На GitHub задайте **Actions → Variables → BOOKING_ENDPOINT**. Встроенный workflow перенесёт его в сборку.

Проверьте все три вида запросов (проживание, аренда с длительностью, чан), реальное получение владельцем, сетевую ошибку, отказ сервера и отсутствие ложного результата. Выключение переменной и новая сборка возвращают честный демонстрационный режим.
