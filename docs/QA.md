# Проверка проекта

Дата: 10 октября 2026 года.

## Выполнено

- `npm run dev -- --hostname 127.0.0.1 --port 3001`: сервер запущен, страница отвечает HTTP 200, первый экран отрендерен.
- `npm run build`: успешная production-сборка Next.js, статический маршрут `/` и страница ошибки. Для воспроизводимой сборки используется Webpack.
- `npm run typecheck`: без ошибок TypeScript.
- `npm test`: 7 групп тестов пройдено. Проверены оба барнхауса, коттедж, баня и гриль-домик, чан, обязательность полей, несуществующая/прошлая дата, выезд после заезда, телефон, положительные целые гости, положительная длительность и часовой пояс Тулуна.
- Chromium / Playwright: ширины 320, 375, 390, 768, 1024 и 1440 px. Горизонтального переполнения нет.
- Проверены мобильное меню (открытие, Escape, переход по ссылке), автоматический выбор объекта, фокус формы, ошибки рядом с полями и подготовка и копирование запроса без сообщения об отправке.
- Проверена смена полей проживания / бани / гриль-домика / чана. Скрытые неприменимые поля не попадают в текст и payload. Чан не содержит длительности и почасового расчёта.
- Галерея: модальное открытие, стрелки, Home/End, переход с последнего кадра на первый, Escape, свайп (синтетическое касание), удержание фокуса внутри и возврат фокуса в исходную кнопку.
- FAQ открывается клавишей Enter. Интерактивные элементы имеют заметный focus.
- В проверенной странице нет ошибок JavaScript, ответов 4xx/5xx для ресурсов и сломанных фотографий.
- axe-core: после исправления контраста нет автоматических нарушений WCAG 2 A/AA и WCAG 2.1 AA на проверенной странице. Это автоматическая проверка, а не полный аудит со скринридерами.
- Экспорт с `NEXT_PUBLIC_BASE_PATH=/solnechnaya-zaimka` проверен в браузере. Изображения, локальные шрифты, CSS и JS загружаются из подпапки, Open Graph и canonical используют полный адрес. Проверена работа кнопки выбора объекта.
- Без JavaScript статическое содержимое видно; форма отключена и содержит объяснение, чтобы не отправить персональные поля стандартным GET-запросом.

## Исправления после UX-аудита

- Палитра обновлена по просьбе пользователя: светлые фоны заменены тёмными; глубокий зелёный затем заменён тёплым графитом в сочетании с основным зелёным, текст — тёплым оттенком слоновой кости, акценты — латунью. Повторная проверка axe-core на новой палитре не выявила автоматических нарушений контраста.
- Увеличены текст описаний, подписи и содержимое полей. На телефонах размер ввода 16 px предотвращает автоматическое увеличение в iOS.
- Диагональные стрелки заменены SVG: отображение не зависит от наличия символа в системном шрифте.
- Основная кнопка первого экрана на телефоне занимает полную ширину; вторичная расположена ниже.
- Баня и чан на телефоне размещены отдельными вертикальными блоками, чтобы фотографии и текст не сжимались.
- Карточка коттеджа проверена после декодирования отложенно загружаемого фото; загрузка вне первого экрана остаётся lazy.
- Текстовые эскизы отделены от реальных фотографий и прямо подписаны.
- Для экспорта добавлен `.nojekyll`, префикс ресурсов проверен отдельно.

## Ограничения перед запуском

Реальная отправка не подключена и не проверялась: сейчас работает честная демонстрационная форма. Сведения и фотографии из OWNER-CHECKLIST.md должны быть получены и проверены владельцем.

Для GitHub подготовлены отдельная ветка, проверка изменений в CI и workflow публикации из main. Публикация на Pages выполняется после объединения pull request и выбора GitHub Actions в Settings → Pages. Дополнительное размещение через Sites в этой среде недоступно: сетевой прокси запрещает загрузку вспомогательного пакета Sites. Локальная сборка и подготовка GitHub Pages завершены.

Проверки выполнены в Chromium. Safari/iOS, Firefox, реальные мобильные устройства и чтение со скринридером отдельно не проверялись. Рекомендуется финальная проверка на устройствах гостей после добавления реальных контактов, изображений и канала доставки заявок.

## Обновление оформления

Главное фото реки восстановлено по просьбе пользователя с помощью обработки изображения (1672 × 940 px) и сохранено в WebP; оригинал остаётся в галерее. Первому изображению задан высокий приоритет загрузки. Тёмная палитра проверена в production-экспорте с префиксом GitHub Pages: ширины 320–1440 px без переполнения, мобильное меню, выбор объекта, ошибки формы, галерея и режим без JavaScript. Ошибок JavaScript и загрузки ресурсов нет. После изменения палитры проведена повторная автоматическая проверка WCAG 2 A/AA и WCAG 2.1 AA.

## Сочетание зелёного и графита

По уточнению пользователя глубокий зелёный заменён тёплым графитом. Основной зелёный `#214738` сохранён в секциях проживания, галереи и заключительного приглашения; шапка, базовый фон, баня и чан, форма и подвал используют нейтральные тёплые оттенки графита. Латунь и тёплый светлый текст сохранены. Production-экспорт и автоматическая проверка контраста повторены после замены палитры.
